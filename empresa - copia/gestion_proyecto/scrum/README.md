# Gestión del proyecto — Scrum

Metodología obligatoria para el seguimiento del proyecto.
Estado: propuesta documentada; no se acredita ejecución de sprints.

El backlog y la distribución de 500 horas se encuentran en ../../docs/PLAN_PROYECTO.md.
Registrar aquí, cuando ocurran, planificación del sprint, responsables, tareas, evidencias de revisión y retrospectiva.
Criterio de terminado: código funcional, verificaciones pertinentes aprobadas, documentación actualizada y evidencia de revisión.
No inventar reuniones, aceptación ni fechas de actividades no realizadas.
