## ALC-01. Identificación y propósito

El proyecto se titula «Proyecto de Desarrollo de un Sistema Inteligente de Análisis de Riesgo Crediticio». Se plantea para PluriOne S.A. de C.V., cuyo nombre comercial es Develop Talent & Technology, dedicada a servicios de consultoría, desarrollo de software y capacitación TI.

El objetivo general es desarrollar un sistema inteligente para el análisis de riesgo crediticio. El alcance propuesto contempla analizar historiales crediticios, comportamiento de pago, ingresos, endeudamiento y variables económicas mediante inteligencia artificial para calcular puntajes de riesgo, detectar posibles incumplimientos y generar recomendaciones para la aprobación o seguimiento de créditos.

Esta descripción expresa lo que se pretende construir, no confirma que todas las funciones estén implementadas o validadas. Las recomendaciones del prototipo no constituyen autorizaciones reales de crédito.

## ALC-02. Tecnologías obligatorias

El documento exige utilizar Python, FastAPI, React.js, Azure OpenAI Service, Azure Machine Learning, Azure AI Search, PostgreSQL, Power BI, Docker, GitHub Actions, Microsoft Entra ID, APIs financieras y Scrum.

La inclusión en esta lista es un requisito, no una evidencia de integración. La existencia de una carpeta o de documentos de prueba tampoco acredita que un servicio esté conectado.

## ALC-03. Objetivos específicos

- Analizar información financiera y crediticia.

Son beneficios esperados. El documento no aporta mediciones que demuestren una reducción real del incumplimiento ni un impacto empresarial ya conseguido.
