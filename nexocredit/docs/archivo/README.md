# Archivo documental histórico

Se conserva aquí el antecedente documental PRD/MVP. El 14/10/2026 se retiraron a la Papelera los recursos de la plantilla antigua, `main-original.jsx`, `icons.svg`, los manifiestos npm originales y sus dependencias, después de comprobar que no participan en la aplicación activa. El código activo utiliza exclusivamente `frontend/package.json` y `frontend/node_modules`.

Esta carpeta no se utiliza para ejecutar, compilar ni probar el sistema. No ejecutar npm aquí. La limpieza no eliminó los documentos actuales, las evidencias, los modelos de IA, las llaves ni los datos privados.

También se conserva el [PRD/MVP combinado anterior](PRD_MVP_NEXOCREDIT.md). Para la revisión actual, usar los documentos separados [PRD](../producto/PRD_NEXOCREDIT.md) y [MVP](../producto/MVP_NEXOCREDIT.md).
